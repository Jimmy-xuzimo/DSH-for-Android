A FEW THINGS TO KNOW

开始之前，
了解多一点。

让选择有依据，也让能力边界保持清楚。

是在手机上离线运行大模型吗？
不是。DSH 引擎、工作区和工具在本机运行；模型推理由你选择的 API 服务完成。应用不附带离线大模型，也不提供模型请求中转。
手机和平板的体验有什么不同？
手机使用底部导航和左侧会话抽屉；窗口足够宽时，可以展开会话侧栏，设置也能采用分类与详情双栏。布局按照当前窗口尺寸变化，适应横竖屏和分屏，而不是只判断设备型号。
能用 Git、终端、插件和 MCP 吗？
随包提供 Git、Bash、搜索及交互 PTY。支持与已打包运行时兼容的 JavaScript 插件、网络 MCP 和使用随包解释器的本地 MCP。需要额外原生程序或桌面平台的扩展，需要独立适配；桌面电脑控制默认禁用。
密钥、工作区与命令权限如何处理？
工作区位于应用私有目录，凭据由应用内服务保存，并由 Android Keystore 保护相关加密材料。密钥草稿可在原生输入框显示或隐藏，不进入设置快照。命令默认关闭；开启后可访问应用获准的文件与网络，不是严格的单工作区隔离。
与完整 Linux 用户空间路线有什么区别？
本项目为 Android/Bionic 构建运行时，避免初始化完整 Ubuntu 用户空间，并提供原生 Material 设置。代价是不能直接运行任意 glibc/Linux 程序。以 DSHA 为代表的 Ubuntu/proroot 路线有不同的兼容性取舍；没有跨项目性能基准，不宣称速度或稳定性领先。
以后 DSH 更新，移植版怎么维护？
通过锁定的上游提交、源码校验值和可追踪补丁准备升级候选；补丁契约发生变化会停止构建。升级需要重新编译、打包和验证。应用不会从可写数据目录下载未知 ELF 后直接执行。阅读维护流程 ↗
所有设备和功能都已经验证了吗？
没有。本版已记录 Android 10 回归、Android 16 正式包及多组窗口测试，但 ARM64 实体手机/平板、真实 16 KB 页设备、全部输入法和厂商后台策略尚未完整验证。第三方插件和未来模型能力也需分别测试。请查看 Release 内的验证报告。
