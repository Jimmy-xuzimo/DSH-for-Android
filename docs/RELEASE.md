独立安装的 DSH 安卓移植重构预览版，支持 Android 10+ 手机和平板，无需 Termux、root 或 Shizuku。上游固定为 `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`，CLI `0.2.1-rc.3`。

采用 Kotlin 外壳、APK 安装目录中的原生 Node/Bash/Git/搜索工具与上游 Web UI，补齐移动布局、软键盘、安全区域、私有工作区、凭据保护和本地认证。支持兼容的 JavaScript 插件和两类 MCP；桌面专属能力不提供支持。

**这是预览版。ARM64 APK 已构建和正式签名，尚未经过 ARM64 真机验证。** x86_64 模拟器覆盖 Android 10/12/14/15/16，另有 16 KB 页运行记录。真实模型 API 和剩余故障、硬件矩阵未全部完成，详见验证报告。

先导出旧版数据、卸载旧调试签名版本，再安装新版；应用标识仍为 `com.dshmobile.shell`，不自动迁移旧会话。需要 Chromium 113 或更新的 Android System WebView。模型使用自行配置的在线 API，不含离线大模型。

手机和平板选择 ARM64 APK，x86_64 APK 用于相应模拟器。对照 `SHA256SUMS` 校验下载文件。命令默认关闭，开启前请阅读原生菜单的权限说明。
