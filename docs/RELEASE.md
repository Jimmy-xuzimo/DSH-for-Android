# v1.0.0 — Android 工作区与 Material 3 交互

首个 1.0 正式版本。应用标识 `com.dshmobile.shell`，版本代码 102。

## 本版内容

- 可隐藏的左侧会话列表：手机使用 Material 抽屉和底部导航，平板使用可收起侧栏。
- 整合设置和单一外观入口：默认字体保持不变，统一字体选择，随包 Noto Sans SC 授权允许商用。
- Android 12+ 动态配色与五套 Material Color Utilities 生成的配色，支持深浅色。
- 组件内置动画、页面/侧栏非线性过渡和全局动画开关；关闭后直接切换，尊重系统设置。
- 提供商默认 API 地址预填；保留已有地址覆盖。在线获取实际模型目录，自定义提供商优先，保留手动添加。
- 修复密钥显示：原生输入框内显示/隐藏，失焦和滚动不丢失草稿；不将密钥放进设置快照。
- 统一安卓自适应图标、Android 13+ 单色图标与网页品牌图标。
- 全新项目网站、架构说明、维护文档与第三方声明。

## 安装

- ARM64：手机和平板；x86_64：模拟器。
- Android 10+，WebView Chromium 113+。
- 已有同签名预览版可升级；旧调试签名版需先导出重要数据，再卸载安装。
- 需要自行配置服务商 API；不包含离线大模型。默认关闭命令权限，开启前阅读应用权限边界。

## 验证与限制

本地 21 项 Android 10 测试通过，覆盖 12 组设置窗口和 4 组会话侧栏；Android 16 正式包及 3 次窗口变更通过。

发布资产中的 `VALIDATION.md`、`BUILD-RECORD.json` 和 `evidence/` 记录本版实际结果。模型刷新及完整 Agent 工具往返用本地模拟服务测试，未发起新增付费生成请求。

ARM64 真机、当前版本在真实 16 KB 页设备上运行、全部中文输入法及厂商后台策略未完成验证。ABI/ELF 对齐通过不代替设备验证。桌面电脑控制、额外原生扩展和所有未来模型不保证兼容。
