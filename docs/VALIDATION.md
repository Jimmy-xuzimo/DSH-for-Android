## 窗口范围

设置矩阵包含 320dp 窄手机、约 411dp 手机、手机横屏、500dp 分屏、600/839/840dp 断点、4:3 / 16:10 / 16:9 平板、约 1600dp 大窗口及 400dp 低矮窗口。读取 Android 实际覆盖尺寸；断点处的系统舍入允许约 1dp 差异。12 个窗口是模拟器配置，不是 12 台实体设备。

会话侧栏截图由同步的 Compose 帧直接捕获，未通过图片编辑伪造布局。网页 hero 使用实际模拟器截图；API 目录卡片明确标注为流程示意。

## 安全与实现边界

- 原生设置调用 DSH 原有验证和持久化，透明控制器不参与用户触控或读屏。
- 密钥草稿只驻留内存，关闭控件/编辑器后清理，不写入恢复 Bundle、设置快照、日志或导出。已保存凭据不会为显示操作读回。
- 受信任回环来源限制、未授权请求拒绝、无效控件 ID 拒绝和密码脱敏保留。
- 命令在应用权限范围内运行，不是严格的单工作区隔离；默认关闭，保留工具审批。
- `WindowRecomposerPolicy` 工厂属于已锁定 Compose 版本的内部接口；升级时必须复查契约并重跑窗口/正式包测试。固定 Activity Recomposer 导致缩放停帧的问题已修复。
- 对话、编辑器和终端仍使用 DSH WebView 内容，不能宣称全部界面均为原生。
