# 1.0.0-preview.2：统一 Material 3 设置

记录日期：2026-10-27。独立签名的本地预览版，未在本轮推送 GitHub 或发布新 Release。版本代码 101，应用标识 `com.dshmobile.shell`。上游仍固定为 `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`。

## 设置实现

设置分类、通用设置、模型配置、内置插件、Agent 预设及其输入、开关、选择、按钮和弹窗均由 Compose Material 3 控件显示。删除“模型与 DSH 详细设置”旧网页入口。外观、会话/代码/终端字号和字体只保留在“外观与文字”；旧页面不再注册第二套可见控件。首次配置模型也使用原生设置入口，不显示旧网页首次使用引导。

实现位于 `DshMaterialShell.kt`、`MaterialSettings.kt` 和 `app/src/main/assets/settings-bridge.js`。DSH 继续负责设置校验、插件逻辑、凭据和持久化，原生控件通过受信任回环主框架内的语义控制器桥调用这些逻辑。底层设置页面保持运行，但透明、不可触控，也不进入读屏焦点；它不是向用户显示的设置界面。此适配依赖上游语义角色和设置槽位，升级必须复查补丁与设备测试。

密码输入值不进入原生设置快照，输入期间仅保留在内存，不写入界面恢复 Bundle 或测试日志；保存后由原有 Keystore 保护的 DSH 凭据层管理。控制器只接受当前设置范围内的有效控件 ID 和有限操作，不接受任意选择器、脚本或文件路径。

## 适配与修复

- 使用官方自适应导航组件，按当前窗口宽高选择底栏或导航轨；宽窗口中的设置分类与内容分栏显示。设置列表限制阅读宽度，正文和控件可滚动，不用固定平板宽度限制手机。
- 使用官方 Slider、Switch、OutlinedTextField、DropdownMenu、ListItem、按钮、TopAppBar、ModalBottomSheet 和弹窗组件，保留组件动效、反馈和无障碍语义。主题下拉选择可在大字体下换行；软键盘出现时收起底栏。
- 关闭旧首次使用引导的协调器，防止它在后台自动关闭设置控制页面。控制器关闭时清空旧快照，并与当前原生页面同步恢复。
- 设置桥按受信任来源在文档启动阶段注册，兼容 DSH 清理启动令牌地址；更新使用节流，避免流式状态持续变化时无法回传设置结果。
- 控件等待页面就绪；保留 MATCH_PARENT WebView 布局参数，防止百分比高度为零。
- 模型顺序不把网页拖拽手柄伪装成普通按钮：用官方图标按钮上移/下移，通过上游已有键盘排序处理器修改真实草稿，并正确禁用首尾方向。测试新增模型、填入 ID、上移、删除该临时草稿，确认原模型顺序恢复且未保存凭据。

## 测试方法与证据边界

实际结果：Android 10 全套 **17 项设备测试通过（165.043 秒）**，其中包含 12 组窗口的控件显示和调用、模型顺序草稿操作；JVM 单元测试 **3 项通过**，Node 测试 **6 项通过**。Debug Lint 和 ARM64 Release Lint 通过，保留依赖更新/平台兼容性警告，没有关闭检查。上游 **8 项构建、2 项类型检查通过**。

Android 16 / API 36 / WebView 133 / x86_64 / 4 KB 页上，正式签名、经过 R8 缩减的 APK 升级安装后验证通过，返回 `SIGNED_PREVIEW_NATIVE_SETTINGS_OK`、版本 `1.0.0-preview.2`。验证了实际原生字号滑块写回与恢复、模型编辑器输入框以及旧控制页面透明。两种 ABI 共 26 个 ELF 的 16 KB PT_LOAD 对齐和两份 APK 的签名、ZIP 对齐检查通过；这不等于在 ARM64 或 16 KB 页设备上运行过本版。

最新 APK 的完整 agent 往返也使用模拟模型通过：write → read → edit → grep → bash，实际中文文件、Git 2.51.2、ripgrep 14.1.1 的结果回传到模型并显示成功。手机 Web 内容宽度 412，滚动宽度 412，无横向溢出。

开发回归在 Android 10 / API 29 / x86_64 模拟器进行。窗口矩阵覆盖 320dp 窄手机、常用手机、手机横屏、500dp 分屏宽度、600/839/840dp 断点、4:3/16:10/16:9 平板、1600dp 大窗口及低矮窗口。在每组窗口检查官方滑块和导航的可见范围，并实际切换 DSH 开关再恢复。Android 在精确断点附近可能对窗口覆盖值产生约 1dp 舍入，测试同时核对实际尺寸和可用控件。

其余回归覆盖：设置分类与模型/插件内容确实载入、下拉选择及开关改变真实 DSH 状态、插件搜索输入、单一字号入口、异步保存后引擎重启、1.6 倍字体与软键盘、密码脱敏及无效控件 ID 拒绝。原有 Node、Bash、PTY、Git、JS 插件、两类 MCP、凭据保护和归档安全测试继续保留。

正式签名且经过 R8 缩减的 APK 另用纯 Android 框架测试工具验证安装、原生字号滑块写回 DSH 和模型编辑器输入框。该工具不依赖调试版内部类，也不启用生产包 WebView 调试。源码在 `tests/release-smoke/`。

真实 API 在上轮只做过一次最小请求（输入 8、输出 1 token），本轮不再使用真实密钥。模型工具回归使用本地模拟服务，不能据此宣称所有真实模型服务均已验证。

ARM64 安装包需在实体手机/平板验证。显示尺寸覆盖不是实体折叠屏、自由窗口、全部中文输入法或厂商后台策略的替代。额外原生程序和桌面专属扩展仍不支持，第三方自定义控件也需要独立兼容测试。本版保留 preview 标识。
